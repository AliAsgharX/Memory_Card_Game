# 🧠 Memory Card Game

A simple and fun memory card matching game built with **HTML**, **CSS**, and **JavaScript**. Flip the cards, find the matching pairs, and test your memory!

## 🎮 Live Demo

> Add your live link here after deploying (for example, GitHub Pages):
> `https://aliasgharx.github.io/Memory_Card_Game/`

## ✨ Features

- 4 × 4 grid with 16 cards
- Click a card to flip it and see the picture
- Matching cards stay open
- Cards that do not match flip back
- Clean and responsive design
- No libraries or frameworks needed — pure HTML, CSS, and JavaScript

## 🕹️ How to Play

1. Click any card to flip it.
2. Click a second card.
3. If the two pictures match, they stay face up.
4. If they do not match, they flip back — so remember where they were!
5. Match all the pairs to win.

## 🛠️ Built With

| Technology | Purpose |
| ---------- | ------- |
| HTML5 | Page structure and card layout |
| CSS3 | Styling, card flip effect, and layout |
| JavaScript | Game logic (flipping, matching, and checking cards) |

## 🚀 Getting Started

No installation is needed.

### Run locally

1. **Clone the repository**
   ```bash
   git clone https://github.com/AliAsgharX/Memory_Card_Game.git
   ```
2. **Go into the folder**
   ```bash
   cd Memory_Card_Game
   ```
3. **Open the game**
   Open `index.html` in your browser (double-click the file).

### Optional: Run with a local server

If you use VS Code, install the **Live Server** extension, right-click `index.html`, and choose **Open with Live Server**.
